แถบ agent — หลายตัวในบ้านเดียว

แถบซ้ายสุดบอกว่า ใครกำลังทำงาน

  • ช่องแรกคือ agent ตัวที่ใช้อยู่ — ชื่อย่อและสถานะ (เช่น main — ready)
  • ท้ายแถบมี 2 ปุ่ม: ตั้งค่า workspace และเพิ่ม agent
  • หนึ่ง workspace รับ agent ได้สูงสุด 8 ตัว

วันนี้เรามี main ตัวเดียว — เดี๋ยวช่วงบ่ายเราจะเพิ่มตัวที่สอง (module Multi-agent)
