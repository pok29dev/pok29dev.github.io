ความแตกต่างจากเว็บ AI สำหรับบุคคลทั่วไป

เว็บ AI สำหรับบุคคลMedia Tools ใน thClaws
การนำเข้าไฟล์ต้องอัปโหลดเองทีละไฟล์ชี้ path ได้เลย หรือให้ agent ค้นหาไฟล์ให้
การต่อยอดงานทำมือ (ดาวน์โหลดมาประกอบในโปรแกรมอื่น)สั่งทำต่อในบทสนทนาเดียว: ภาพ → คลิป → เสียงพากย์
ข้อมูลออกนอกองค์กรหรือไม่ขึ้นกับเงื่อนไขบริการที่สมัครออกผ่าน gateway ที่องค์กรควบคุม
ต้นทุนสมัครรายเดือนแยกผู้ให้บริการคิดต่อการใช้ ผ่าน gateway ของบริษัท (ตรวจสอบใบเสร็จได้)
ความสม่ำเสมอเปลี่ยนคน = เปลี่ยนผลลัพธ์เขียน workflow/คู่มือไว้ ใช้ซ้ำได้ทั้งทีม

Media Tools ทำให้ AI ทำงานต่อเนื่องจนเป็นไฟล์ที่นำไปใช้ได้จริง โดยข้อมูลยังอยู่ภายใต้การควบคุมขององค์กร

การเปิด/ปิด และการเข้าถึง

เรื่องข้อเท็จจริงในระบบผลต่อผู้ใช้งาน
สวิตช์เปิดMenu → Media tools หรือตั้งค่า "imageToolsEnabled": true ใน .thclaws/settings.jsonหากปิดอยู่ เครื่องมือกลุ่มนี้จะไม่มีให้เรียกใช้
สถานะ "ถูกล็อก"เมื่อองค์กรสั่งผ่าน gateway สวิตช์จะแสดงเป็น lockedผู้ใช้กดปิดเองไม่ได้ — เป็นการออกแบบโดยเจตนา
ขอบเขตโมเดลที่เรียกได้Gateway ปล่อยเฉพาะโมเดลที่องค์กรซื้อสิทธิ์โมเดลที่ไม่อยู่ในรายชื่อ = ใช้ไม่ได้ แม้จะพิมพ์ชื่อถูกต้อง
ค่าใช้จ่ายคิดผ่าน gateway (metered) ตามอัตราของโมเดลต้องตรวจสอบก่อนสั่งวิดีโอหรือภาพความละเอียดสูง

⚠️ ข้อควรระวัง: งดถ่ายภาพหน้าจอบทสนทนาแล้วเผยแพร่โดยไม่ตรวจสอบ — งานที่ออกจากระบบอาจมีข้อมูลภายในบริษัทติดไปด้วย

ภาพรวมเครื่องมือ 7 รายการ

กลุ่มเครื่องมือรับเข้าให้ออกใช้กับงานแบบไหน
ImageTextToImageคำอธิบาย (prompt)ไฟล์ .pngโปสเตอร์ ภาพประกอบ ภาพสินค้า mockup
ImageImageToImageภาพต้นฉบับ + คำสั่งแก้ไขไฟล์ .png ใหม่ตัดพื้นหลัง เปลี่ยนสไตล์ ปรับแสง
VideoTextToVideoคำอธิบายฉากjob_id → .mp4คลิปสั้นเมื่อไม่มี footage เดิม
VideoImageToVideoภาพนิ่ง + คำสั่งเคลื่อนไหวjob_id → .mp4ใช้บ่อยที่สุด — คลิปจากภาพที่มีอยู่แล้ว
VideoMediaJobStatusjob_idสถานะ running/done/failedตรวจสอบผลคลิป — ไม่เสียค่าใช้จ่ายเพิ่ม
VoiceTextToSpeechข้อความ + เสียง + โทนไฟล์ .wavเสียงพากย์ e-learning IVR
ตรวจWatchVideoไฟล์วิดีโอหรือเสียงคีย์เฟรม + ข้อความถอดเสียงQC งาน ถอดเสียงประชุม

Video: คลิปสั้น 4–8 วินาที · จังหวะกล้องช้า ๆ (push-in, orbit) · เปลี่ยนภาพนิ่งเป็นคลิปโฆษณา social

⚠️ ข้อจำกัด

Image: ❌ ตัวอักษรภาษาไทยมักสะกดเพี้ยน · ❌ ตัวเลข/ตารางที่ต้องการความแม่นยำ · ❌ โลโก้ตาม brand guide 100%

Video: ❌ คลิปยาวหลายฉาก · ❌ Lip-sync แบบเป๊ะ · ❌ ตัวหนังสือไทยในวิดีโอ · ❌ กล้องอาจซูม/ครอปจนวัตถุหลุดเฟรม

Voice: ❌ อ่าน markdown/ตัวเลขรูปแบบพิเศษ · ❌ บังคับจังหวะตรงวินาที · ❌ ร้องเพลง · ❌ สำเนียงไทยถิ่นเจาะจง

🟢 ฝึกปฏิบัติ (3 นาที · ต้นทุนคนละ ~$0.03)

  • พิมพ์คำสั่ง 1 บรรทัด ให้สร้าง ภาพ 1 ใบ ตามงานของตนเอง → บันทึก path ที่ได้
  • พิมพ์ต่อ: "ทำอีก 3 แบบ สไตล์ต่างกัน แต่สินค้าเดิม" → เปรียบเทียบ 4 ภาพ (นี่คือวิธีเลือกงานที่ถูกต้อง: จ่ายถูกเพื่อทดลอง)
  • สั่ง ImageToImage จากภาพที่เลือก: "เปลี่ยนฉากหลังเป็นห้อง server ตู้ rack เบลอ คงรายละเอียดสินค้าไว้ทั้งหมด ห้าม redesign"
  • (เฉพาะห้องที่อนุมัติงบ) สั่งคลิป 5 s จากภาพข้อ 3 กล้อง orbit รอบสินค้า → สังเกตจังหวะ running → done + ตรวจด้วย WatchVideo

เกณฑ์ผ่าน: ตอบได้ 3 ข้อ — ไฟล์อยู่ที่ใด / ราคาภาพละเท่าใด / หากต้องการเปลี่ยนเฉพาะฉากหลังต้องสั่งอย่างไร

⚠️ งดทดลองพิมพ์ omni, ltx หรือ iapp — ไม่เปิดให้ใช้ใน deployment นี้
