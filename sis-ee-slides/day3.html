Skill คือคู่มือปฏิบัติงานที่ AI สามารถอ่านและปฏิบัติตามได้

นิยาม: คู่มือการทำงาน (SOP) ในรูปแบบที่ AI เปิดใช้งานโดยอัตโนมัติ เมื่อลักษณะงานในบทสนทนาตรงกับเงื่อนไขการเรียกใช้ (trigger) ของคู่มือฉบับนั้น

องค์ประกอบคำอธิบาย
ชื่อ (name)ชื่อเรียก เช่น office-apps, meeting-minutes-th
คำอธิบาย / triggerข้อความที่กำหนดว่า "งานประเภทใดควรเรียกใช้ Skill นี้"
เนื้อหาคู่มือ (SKILL.md)ขั้นตอน รูปแบบรายงาน ข้อห้าม และการตั้งชื่อไฟล์ผลลัพธ์
ไฟล์ประกอบ (ถ้ามี)สคริปต์ แม่แบบ (template) และตัวอย่าง ซึ่งจัดเก็บไว้ในโฟลเดอร์เดียวกับ Skill

กล่าวอย่างง่าย: Skill คือชุดความรู้เกี่ยวกับวิธีการทำงานที่มอบให้กับ AI ไม่ใช่ความสามารถใหม่ในระดับโปรแกรม แต่เป็น มาตรฐานการทำงานขององค์กร ที่ฝังไว้ในระบบ

ไม่มี Skillมี Skill
การสั่งงานต้องเขียนคำสั่งยาวเพื่อระบุรูปแบบเองทุกครั้งบรรยายงานเป็นภาษาธรรมชาติ ระบบเลือก Skill ให้เอง
ความสม่ำเสมอรูปแบบเปลี่ยนตามผู้สั่งหรือสถานการณ์ได้รูปแบบเดียวกันทุกครั้งตามคู่มือ
มาตรฐานองค์กรAI ไม่ทราบกฎเกณฑ์เฉพาะขององค์กรกฎเกณฑ์ถูกกำหนดไว้ใน Skill แล้ว
การส่งต่องานขึ้นกับทักษะการเขียนคำสั่งของแต่ละคนทุกคนได้ผลลัพธ์คุณภาพเท่าเทียมกัน
ความเสี่ยงลืมข้อกำหนดลืมระบุ → งานผิดข้อกำหนดถูกฝังไว้ใน Skill แล้ว

สรุป: Skill เปลี่ยนทักษะส่วนบุคคลให้เป็นสินทรัพย์ขององค์กร ที่ทุกคนใช้ได้เท่าเทียม

สรุปอย่างย่อ: Tool คือมือและตา · Skill คือความรู้เกี่ยวกับวิธีการทำงาน · MCP คือสายเชื่อมต่อไปยังระบบอื่น · เนื้อหาในวันนี้มุ่งเน้นที่ Skill

ขอบเขตที่สำคัญใน Enterprise Edition

  • thClaws Enterprise ดึงแคตตาล็อกจาก Marketplace ขององค์กรเป็นหลัก ไม่ใช่จากแหล่งสาธารณะ — ผู้ดูแลระบบเป็นผู้กำหนดแหล่งข้อมูลที่อนุญาต
  • สิทธิ์ในการ ดู กับ ติดตั้ง/ลบ อยู่คนละระดับกัน (skills.read กับ skills.write) บางตำแหน่งอาจดูได้อย่างเดียว ซึ่งเป็นไปตามการออกแบบของระบบ
  • บาง Skill อาจถูกระงับตามนโยบายความปลอดภัยขององค์กร เช่น Skill ที่มีสคริปต์ .sh/.py แนบมา ระบบจะแสดงข้อความ skill install blocked by org policy กรุณาหยุดดำเนินการและติดต่อฝ่าย IT ทันที ห้ามพยายามติดตั้งซ้ำ
  • Built-in Skill ของ thClaws ไม่สามารถแก้ไขได้ (read-only) — Skill ที่สามารถแก้ไขหรือลบได้คือ Skill ระดับ project หรือระดับผู้ใช้ที่ติดตั้งเพิ่มเติมเท่านั้น

⚠️ ข้อควรระวังด้านความปลอดภัย: การติดตั้ง Skill เท่ากับการนำคำสั่งหรือแนวทางการทำงานจากแหล่งภายนอกมาให้ AI ปฏิบัติตาม ดังนั้น ควรติดตั้งเฉพาะจาก Marketplace ขององค์กร หรือแหล่งที่ฝ่าย IT รับรองเท่านั้น
