เดโม 1 — แปลไฟล์ทั้งไฟล์จากเมนูคลิกขวา

  • เปิดแท็บ Files ของ workspace
  • คลิกขวาที่ชื่อไฟล์ → Translate
  • เลือกภาษาปลายทาง แล้วรอไฟล์ใหม่
  • เปิดไฟล์ผลลัพธ์ เทียบกับต้นฉบับ
เดโมนี้ไม่ต้องพิมพ์ prompt
เมนู Translate เรียก agent ให้ทำงานแทนคุณ — ใช้เมื่ออยากแปลทั้งไฟล์ ไม่ใช่ทีละย่อหน้า
ถ้าไม่เห็นเมนู
ชื่อเมนูขึ้นกับเวอร์ชันที่ติดตั้ง — ใช้ prompt แทนได้ ผู้สอนมีตัวอย่างในสคริปต์
7 / 32

เดโม 1 — ผลลัพธ์ที่ต้องเห็น

  • ไฟล์ใหม่ถูกสร้างขึ้น ไม่ทับต้นฉบับ
  • หัวข้อ ตาราง และลำดับย่อหน้า
  • ชื่อสินค้า คำเฉพาะ และ code ไม่ถูกแปล
  • เทียบ 2–3 ย่อหน้าแรกด้วยตาก่อนเชื่อ

จุดที่คนดูมักพลาด — ไฟล์แปลหน้าตาดี แต่ตัวเลขในตารางเพี้ยน ต้องเปิดเทียบทุกครั้ง

9 / 32

เดโม 2 — สรุปเอกสารยาวให้เหลือหนึ่งหน้า

  • คลิกขวาที่ชื่อไฟล์ → Summarize
  • อ่านสรุป แล้วเปิดต้นฉบับตามที่อ้างอิง
  • ถ้าต้องการรูปแบบเฉพาะ ใช้ prompt ทางขวา
prompt ทางเลือก
สรุปเอกสารนี้เป็น 1 หน้า: ประเด็นหลัก 5 ข้อ ตัวเลขที่ต้องจำ และสิ่งที่ต้องตัดสินใจ — กำกับทุกข้อด้วยหัวข้อหรือเลขหน้าในต้นฉบับ

Summarize ให้สรุปตามที่โมเดลเห็น — ถ้าต้องการหัวข้อตายตัว ใช้ prompt แทนเมนู

10 / 32

เดโม 2 — ผลลัพธ์ที่ต้องเห็น

  • ทุกข้อมีหัวข้อหรือเลขหน้าอ้างอิง กลับไปอ่านต้นฉบับได้
  • แยก “สิ่งที่เอกสารบอก” กับ “ข้อเสนอของ agent” ชัดเจน
  • ไม่มีตัวเลขหรือชื่อที่ไม่มีในเอกสาร
  • บอกว่าสรุปข้ามส่วนใดไป ถ้ามี

สรุปที่ดีไม่ใช่สั้นที่สุด แต่คืออันที่พากลับไปต้นฉบับได้

เดโม 3 — ผลลัพธ์ที่ต้องเห็น

  • ตัวเลขและชื่อจากภาพครบ — เปิดภาพเทียบ 2 จุด
  • มีบรรทัดระบุว่าเนื้อหาส่วนใดมาจากภาพ
  • ไม่มีข้อความที่ agent เติมเองขึ้นมา
  • ไฟล์เป็น md ที่เปิดอ่านได้ ไม่มี markup หลุด

ภาพคือหลักฐาน — ถ้าอ่านไม่ได้ ต้องบอก ไม่ใช่แต่งให้ครบ

เดโม 4 — ผลลัพธ์ที่ต้องเห็น

  • ทุกหัวข้อมี timestamp และเรียงตามวิดีโอ
  • จำนวนหัวข้อสอดคล้องกับความยาว — เปิดดูช่วงท้าย 2–3 จุด
  • ประโยคเปิดและปิดของแต่ละช่วงยังอยู่
  • ถ้าไม่มี transcript ต้องแจ้ง ไม่เดาเนื้อหา

บทความที่ “ไม่ตัด” ต้องยาวพอ ๆ กับวิดีโอ — สั้นกว่านั้นคือตัด

เดโม 6 — ผลลัพธ์ที่ต้องเห็น

  • ทุกราคาตรงกับ pricelist — สุ่มตรวจ 3 บรรทัด
  • ส่วนลดและ VAT แยกบรรทัด ไม่ถูกกลืนในราคาต่อหน่วย
  • ข้อมูลลูกค้า เลขผู้เสียภาษี และที่อยู่ครบ
  • มีรายการ “สิ่งที่ต้องให้คนตรวจก่อนส่ง”

เอกสารที่ออกถึงลูกค้า ต้องมีคนเซ็นชื่อกำกับเสมอ — agent เตรียมให้ ไม่ใช่ส่งเอง

เดโม 8 — ผลลัพธ์ที่ต้องเห็น
