# เรียนลัด thClaws ฉบับอ่านเอง (Self-Study Book)

> **แนวคิดหลักทั้งเล่ม:** *"Chat AI ตอบคำถาม / thClaws ทำงานให้"* — เปลี่ยนจากการถาม มาเป็นการสั่งให้ผู้ช่วย AI ลงมือทำงานจริงบนเครื่องของคุณ
>
> **เหมาะสำหรับ:** พนักงานออฟฟิศ / ผู้ใช้ทั่วไป ที่เคยใช้ ChatGPT, Copilot, Gemini ถาม-ตอบเป็นประจำ แต่ยังไม่เคยมีประสบการณ์ AI Agent
>
> **ข้อแตกต่างจากฉบับอบรม:** เล่มนี้เป็น**หนังสือที่อ่านและลงมือทำเองได้ตามลำพัง** ไม่ต้องมีผู้สอน ไม่ต้องมีคลาสสด — แต่ละบทมีเป้าหมาย เนื้อหา กิจกรรมให้ลองทำ และแบบตรวจความเข้าใจ

---

## หนังสือเล่มนี้คืออะไร

หนังสือเล่มนี้พาคุณจาก "เคยถาม Chat AI" ไปสู่ "ตั้ง thClaws บนเครื่องตัวเอง แล้วใช้ AI Agent + Tools + Skills ทำงานจริงได้" โดยลำดับเนื้อหาตาม**ขั้นตอนการใช้งานจริง** ไม่ใช่ตามทฤษฎี: รู้จัก → ติดตั้ง → ใช้ → ต่อยอด → ไปต่อ

เมื่ออ่านจบทั้งเล่ม คุณจะสามารถ:

1. อธิบายได้ว่า thClaws / AI Agent ต่างจาก Chat AI ทั่วไปอย่างไร และทำไมถึงเป็นแบบ local-first
2. ติดตั้ง thClaws Desktop บนเครื่องตัวเอง และตั้งค่า API Key กับ instruction (global / folder) ได้
3. รัน thClaws ได้ 3 รูปแบบ — CLI / Desktop GUI / One-shot — และเข้าใจบทบาทของ working directory กับ session
4. ส่งคำสั่งแรก และใช้คำสั่งสแลชพื้นฐาน (`/…`) ได้
5. เล่าได้ว่า Built-in tools มีอะไรบ้างที่ทำให้ "ทำงาน" ได้จริง พร้อมลอง 1–2 use case
6. ติดตั้งและเรียกใช้ Skill และรู้วิธีพื้นฐานในการเชื่อม MCP กับงานจริง
7. รู้จัก thClaws.cloud ว่าคืออะไร (3 องค์ประกอบ) ตั้งค่า Access Key แรกอย่างไร และสลับการทำงานระหว่าง desktop กับ cloud ได้
8. วางแผนนำไปใช้ในงานประจำวันของตัวเองได้

## ของที่ควรเตรียมก่อนเริ่ม (อ่านบทนำก่อนทำ)

- คอมพิวเตอร์ **macOS / Windows / Linux** (RAM ≥ 8GB แนะนำ, พื้นที่ว่าง ≥ 500MB)
- **อินเทอร์เน็ต** สำหรับดาวน์โหลดและเรียก API
- **Qwen API Key จาก DashScope** (Key ขึ้นต้น `sk-…` — สร้างฟรี)
- **บัญชี thClaws.cloud** (ใช้ในบท 5 — ปัจจุบันเป็น close-beta ต้องติดต่อ admin ขอ invite; ยังไม่มีก็อ่านแนวคิด/ดูตัวอย่างก่อนได้)
- โฟลเดอร์ทำงานส่วนตัว เช่น `~/thclaws-2hr`

## หมายเหตุสำคัญ

- **เนื้อหาหนังสืออิงคู่มือ `user-manual-th`** ของ thClaws (บท ch01–ch04, ch06, ch07, ch10–ch12, ch14, ch27) — คำสั่ง/โปรแกรม/URL ควรเทียบกับคู่มืออ้างอิงอีกครั้งก่อนนำไปใช้กับงานจริง
- **ตรวจผลลัพธ์เสมอ** — AI ยังมีข้อมูลลวง (hallucination) ได้ อย่าเชื่อผลลัพธ์โดยไม่ตรวจ
- **สั่งให้ชัดเจน** — ยิ่งระบุขั้นตอน/ขอบเขตชัด ผลยิ่งแม่น
