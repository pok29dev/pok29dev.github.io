## วันจันทร์ที่ 10 สิงหาคม 2026

### งานที่ต้องทำวันนี้
1. ตอบอีเมลลูกค้า 5 ฉบับที่ค้างอยู่
2. เตรียมสไลด์นำเสนอผลงานประจำเดือน
3. นัดประชุมทีมขายวันศุกร์
4. อัปเดตข้อมูลยอดขายลงสเปรดชีต
5. ส่งรายงานความคืบหน้าให้ผู้จัดการ

### งานที่ทำเสร็จแล้ว
- [x] ส่งใบเสนอราคาให้ลูกค้า A
- [x] ตรวจสอบสต็อกสินค้าคงคลัง
- [ ] ต่ออายุใบอนุญาตซอฟต์แวร์ (สำคัญ!)

### งานค้าง–เลื่อน
- ต่ออายุใบอนุญาตซอฟต์แวร์ ยังไม่ได้ทำ เลื่อนไปพรุ่งนี้เช้า (ต้องทำก่อนหมดอายุ)
- สไลด์ประจำเดือนทำได้แค่โครง ยังขาดกราฟยอดขายเดือน ส.ค.

### ปัญหา/อุปสรรค
- อีเมลตอบไปได้ 3 จาก 5 ฉบับ ที่เหลือรอข้อมูลราคาเหยือกใหญ่จากพี่ต้น
- ช่วงบ่ายมีลูกค้าโทรเข้ามาแทรกหลายสาย ทำให้ไม่ได้ทำสไลด์ต่อ

### หมายเหตุ
- ลูกค้า B ถามเรื่องโปรโมชันใหม่ — ต้องตอบภายในเย็นนี้
- พรุ่งนี้มีการประชุมแผนกตอน 9:00 น. อย่าลืมเตรียมข้อมูลยอดขายรายเดือน
- อยากให้ผู้ช่วย AI ช่วยสรุปงานประจำวันและเตือนงานที่ค้าง

### ติดต่อประสานไว้
- พี่ต้น (Sales Operation) — ขอราคาเหยือกใหญ่ 6 รายการ
- พี่สาวี — ถามกำหนดส่งแคมเปญโซเชียลมีเดีย

- แบนเนอร์โปรโมชัน "ซื้อ 5 แถม 1" ยังไม่ได้เริ่มออกแบบ

- พี่วิทย์ติดประชุมทั้งวัน ได้คุยแค่ทางแชท

### หมายเหตุ

- หัวหน้าเน้นว่าเคสจากระบบล่มต้องเก็บเป็นหลักฐานไว้ ไม่ใช่แค่บอกปากเปล่า

### ติดต่อประสานไว้
- พี่วิทย์ (หัวหน้าฝ่ายไอที) — นัดคุยเรื่องไทม์ไลน์ซ่อมระบบ
- คุณปาริชาติ (ผู้จัดการร้านค้า) — ขอตัวเลขลูกค้าที่ทักเข้า Line OA

### งานที่ต้องทำวันนี้
- สรุปเคสลูกค้าจาก Line OA ช่วงระบบล่ม 8 ส.ค. ให้เป็นตัวเลข
- เข้าประชุมทีมตอนบ่าย (วาระโปรโมชัน)
- เริ่มทำแบนเนอร์โปรโมชัน
- กรอกสเปรดชีตกลางก่อน 17:30

### งานที่ทำเสร็จแล้ว
- [x] นับเคสได้ 40+ เคส แยกเป็น 2 กลุ่ม: ถามสถานะออเดอร์ กับ ขอยกเลิกแล้วสั่งใหม่
- [x] เข้าประชุมครบ สรุปมติได้

### งานค้าง–เลื่อน
- แบนเนอร์โปรโมชัน ทำได้แค่ร่างแรก ยังไม่ผ่านสายตาหัวหน้า
- เอกสารเปิดตัวกาแฟโอ๊ก ยังไม่ได้เปิดไฟล์เลย

### ปัญหา/อุปสรรค
- ข้อมูลเคสจาก Line OA กระจัดกระจาย ต้องรวบจาก 2 เครื่อง ทำให้เสียเวลาเกือบครึ่งวัน
- รูปแบบแบนเนอร์เดิมที่ทีมเคยใช้หาไม่เจอ ต้องขอจากคุณกมลชนกใหม่

### หมายเหตุ
- ที่ประชุมมีมติให้ขยายโปรโมชัน "ซื้อ 5 แถม 1" อีก 2 สัปดาห์
- ที่ประชุมยืนยันเพดานส่วนลด: ออเดอร์เกิน 100 เหยือก ให้ได้สูงสุด 8%
- ต้องแจ้งมติเรื่องส่วนลดให้ฝ่ายบัญชีรับทราบด้วย ไม่ใช่แค่ทีมขาย

### ติดต่อประสานไว้
- คุณกมลชนก (พนักงานขาย) — ขอไฟล์แบนเนอร์เดิม
- ฝ่ายบัญชี — แจ้งเพดานส่วนลด 8%

- [x] แบนเนอร์แก้เสร็จ 2 ขนาด (สำหรับโพสต์ และสำหรับป้ายหน้าร้าน)
- [x] ส่งวาระประชุมทีมขายให้ทุกคนทางกลุ่มแล้ว

### งานค้าง–เลื่อน

- สไลด์ประจำเดือนค้างที่กราฟยอดขายเดือน ส.ค. (รอตัวเลขปิดเดือน)

### ปัญหา/อุปสรรค

- พี่ต้นลาป่วย เรื่องราคาเหยือกใหญ่ต้องรอต่ออีกรอบ

### หมายเหตุ
- พรุ่งนี้ประชุมทีมขาย ต้องสรุปให้ได้ว่าโปรโมชันที่ขยายออกไปได้ผลแค่ไหน
- หัวหน้าขอให้เตรียมตัวเลข "ยอดขายสัปดาห์ 3–9 ส.ค. = 429,790 บาท" ไว้เทียบกับเป้า 400,000 บาท

### ติดต่อประสานไว้
- พี่วิทย์ — ขอความชัดเจนเรื่องวันซ่อมเสร็จ
- พี่สมชาย — ส่งวาระประชุมรอตรวจ

- [x] ทดลองสั่งซื้อผ่านระบบออนไลน์ 3 ออเดอร์ ใช้งานได้ปกติ
- [x] ส่งสไลด์ประจำเดือนให้ผู้จัดการแล้ว

### งานค้าง–เลื่อน
- [ ] ยังไม่ได้ขอรายงานสรุปสาเหตุระบบล่มเป็นลายลักษณ์อักษรจากฝ่ายไอที
- [ ] เอกสารเปิดตัวกาแฟโอ๊ก ยังไม่เริ่ม ทำได้แค่ตั้งชื่อไฟล์

### ปัญหา/อุปสรรค

- ประเมินความเสียหายชั่วคราวได้ 30,000–40,000 บาท (เป็นโอกาสขายที่หายไปช่วง 11:00–14:00)

### หมายเหตุ

- ที่ประชุมกำชับว่าโปรโมชันที่ขยายเพิ่มต้องมีคนติดตามผลรายสัปดาห์ ไม่ปล่อยจบแล้วจบเลย
- หัวหน้าขอให้เริ่มทำเอกสารเปิดตัวกาแฟโอ๊กจริงจัง เพราะเหลือเวลาถึง 1 ตุลาคมไม่มากแล้ว

### ติดต่อประสานไว้
- พี่วิทย์ — ขอสรุปสาเหตุและบทเรียนเป็นเอกสาร
- พี่สมชาย — รับปากจะช่วยดูโครงเอกสารเปิดตัว

- ตรวจสไลด์กับพี่สาวี (นัดไว้)
- ตามรูปสินค้าอีกรอบ
- ปิดเอกสารเปิดตัวฉบับสุดท้าย
- กรอกสเปรดชีตกลางก่อน 17:30

### งานที่ทำเสร็จแล้ว
- [x] ตรวจสไลด์กับพี่สาวีแล้ว แก้ตาม 4 จุด
- [x] ได้รูปสินค้ามาแล้ว 3 รูป (ยังขาดรูปเหยือก)
- [x] กรอกสเปรดชีตกลางทันเวลา

### งานค้าง–เลื่อน
- เอกสารเปิดตัว: รอรูปเหยือก
- แผนสำรองวัสดุบรรจุภัณฑ์: ยังไม่ได้เริ่ม
- ลูกค้ารายที่ 3: ยังไม่ตอบ

### ปัญหา/อุปสรรค
- รูปเหยือกกาแฟโอ๊กยังไม่มี ต้องใช้รูปเหยือกเดิมไปก่อนชั่วคราว แต่ต้องกำกับให้ชัดว่ายังไม่ใช่รูปจริง
- วันนี้เป็นวันสุดท้ายของเดือน ระบบปิดยอดทำงานช้า กรอกสเปรดชีตแล้วแต่ต้องรอตรวจอีกรอบ

### หมายเหตุ
- ประชุมเปิดตัวพรุ่งนี้ 10:00 ต้องเตรียมลำดับการพูดไว้ล่วงหน้า ไม่พูดสดทั้งหมด

### ติดต่อประสานไว้
- ฝ่ายการตลาด — ขอรูปเหยือก
- ผู้จัดการ — ส่งสไลด์ให้ดูก่อนประชุม

## วันอังคารที่ 1 กันยายน 2026

### งานที่ต้องทำวันนี้
- ประชุมความคืบหน้าเปิดตัวกาแฟโอ๊ก 10:00
- บันทึกงานที่ได้รับมอบหมายเพิ่ม
- อัปเดตสไลด์ตามความเห็นในที่ประชุม
- กรอกสเปรดชีตกลางก่อน 17:30

### งานที่ทำเสร็จแล้ว
- [x] ประชุมจบตามวาระ
- [x] บันทึกงานที่ได้เพิ่ม 3 รายการ
- [x] อัปเดตสไลด์ตามความเห็นในที่ประชุมแล้ว

### งานค้าง–เลื่อน
- เอกสารเปิดตัวยังขาดรูปเหยือก (ค้างมา 5 วัน)
- แผนสำรองวัสดุบรรจุภัณฑ์ ยังไม่ได้เริ่ม ทั้งที่ที่ประชุมถามถึง
- ลูกค้ารายใหม่เหยือกใหญ่รายที่ 3 ยังไม่ปิด
- ยังไม่ได้ยืนยันกับฝ่ายบัญชีเรื่องเพดานส่วนลด 8% ว่าใช้กับการเปิดตัวด้วยหรือไม่

### ปัญหา/อุปสรรค
- ที่ประชุมถามเรื่องแผนสำรองวัสดุบรรจุภัณฑ์ แล้วตอบไม่ได้ ต้องขอโทษและรับปากว่าจะทำ
- ความเห็นเรื่องราคากาแฟโอ๊กยังไม่นิ่ง ที่ประชุมขอให้ยืนยันอีกครั้งก่อนประกาศ

### หมายเหตุ
- กาแฟโอ๊กเปิดตัว 1 ตุลาคม 2026 ราคาที่ใช้คุยกันคือแก้วเดียว 70 บาท และเหยือก 470 บาท แต่ยังรอประกาศอย่างเป็นทางการ
- ที่ประชุมขอให้ทุกฝ่ายส่งงานค้างของตัวเองภายในสัปดาห์นี้ จะได้เห็นภาพว่าอะไรเสี่ยงทำให้เปิดตัวช้า

### ติดต่อประสานไว้
- ฝ่ายการตลาด — ยืนยันราคาเปิดตัว
- ฝ่ายบัญชี — ถามเรื่องส่วนลดช่วงเปิดตัว
- หัวหน้า — ส่งรายการงานค้างของทีมขาย

## วันพุธที่ 2 กันยายน 2026

### งานที่ต้องทำวันนี้
- เขียนแผนสำรองวัสดุบรรจุภัณฑ์ล่าช้า
- ตามรูปเหยือกอีกรอบ
- ติดต่อลูกค้ารายใหม่เหยือกใหญ่รายที่ 3
- กรอกสเปรดชีตกลางก่อน 17:30

### งานที่ทำเสร็จแล้ว
- [x] แผนสำรองฉบับร่างเสร็จ (ระบุทางเลือกซัพพลายเออร์ 2 ราย)
- [x] ติดต่อลูกค้ารายที่ 3 แล้ว ตกลงจะทดลองสินค้าใหม่สัปดาห์หน้า
- [x] กรอกสเปรดชีตกลางทันเวลา

### งานค้าง–เลื่อน
- แผนสำรองยังต้องให้หัวหน้าตรวจ
- รูปเหยือกยังไม่มา ตามมา 6 วันแล้ว
- ยังไม่ได้เช็กกับฝ่ายบัญชีเรื่องส่วนลด

### ปัญหา/อุปสรรค
- การตามเรื่องรูปภาพใช้เวลามากแต่ไม่ได้ผล คิดว่าควรคุยเป็นวาจากับหัวหน้าฝ่ายการตลาดโดยตรง ไม่ควรทักแชทอย่างเดียว
- ซัพพลายเออร์รายที่ 2 ยังไม่ตอบอีเมล ไม่รู้ว่ารับงานได้หรือไม่

### หมายเหตุ
- เรื่องรูปภาพเป็นตัวอย่างที่ดีว่า งานเล็กที่ค้างนาน ๆ จะกลายเป็นตัวถ่วงของงานใหญ่

### ติดต่อประสานไว้
- หัวหน้าฝ่ายการตลาด — ขอคุยนอกรอบเรื่องรูปสินค้า
- ซัพพลายเออร์รายที่ 2 — ตามอีเมล

## วันพฤหัสบดีที่ 3 กันยายน 2026

- เช็กเรื่องส่วนลดกับฝ่ายบัญชี
- กรอกสเปรดชีตกลางก่อน 17:30

### งานที่ทำเสร็จแล้ว

- [x] ฝ่ายบัญชียืนยันว่าเพดานส่วนลด 8% ใช้กับการเปิดตัวด้วย
- [x] กรอกสเปรดชีตกลางทันเวลา

### งานค้าง–เลื่อน
- [ ] รูปเหยือก ยังไม่มา (แต่นัดแล้วว่าส่งวันศุกร์)

- [ ] ลูกค้ารายใหม่เหยือกใหญ่รายที่ 3 ยังไม่ปิดการขาย

- งานค้างหลายรายการกระจายอยู่หลายเจ้าของ ตามคนเดียวไม่ไหว ต้องให้หัวหน้าช่วย

### ติดต่อประสานไว้
- ฝ่ายบัญชี — ยืนยันเพดานส่วนลดเป็นลายลักษณ์อักษร

- ปิดเอกสารเปิดตัวฉบับสุดท้าย
- อัปเดตสไลด์ประจำเดือนด้วยตัวเลขปิดเดือน ส.ค. ฉบับจริง
- ประชุมทีมขายตอนเช้า
- กรอกสเปรดชีตกลางก่อน 17:30

### งานที่ทำเสร็จแล้ว
- [x] ได้รูปเหยือกแล้ว
- [x] ปิดเอกสารเปิดตัวฉบับสุดท้าย ส่งให้หัวหน้าลงนามแล้ว
- [x] อัปเดตสไลด์ประจำเดือนเสร็จ
- [x] ประชุมทีมขายจบตามวาระ ครบเดือนนี้
- [x] กรอกสเปรดชีตกลางทันเวลา

### งานค้าง–เลื่อน
- [ ] ลูกค้ารายใหม่เหยือกใหญ่รายที่ 3 ยังไม่ปิดการขาย (นัดทดลองสินค้าสัปดาห์หน้า)
- [ ] ลูกค้ารายใหม่เหยือกใหญ่รายที่ 2 ยังไม่ตอบกลับใบเสนอราคาชุดจัดเลี้ยง 20 ท่าน
- [ ] ยังไม่ได้ทำเอกสาร "เงื่อนไขเหยือกใหญ่" ให้เป็นฉบับใช้จริง (ตอนนี้เป็นร่าง)
- [ ] ลูกค้าที่ทัก Line OA ช่วงระบบล่ม 8 ส.ค. ยังไม่ได้ติดต่อกลับทุกราย
- [ ] ยังไม่ได้รับรายงานสาเหตุระบบล่มเป็นลายลักษณ์อักษรจากฝ่ายไอที (ค้างตั้งแต่ 14 ส.ค.)
- [ ] แผนสำรองวัสดุบรรจุภัณฑ์ รอหัวหน้าตรวจ
- [ ] ยังไม่ได้นัดถ่ายภาพสินค้ากาแฟโอ๊กชุดจริงก่อนเปิดตัว 1 ต.ค.
- [ ] ยังไม่ได้ทำตารางติดตามผลหลังเปิดตัวกาแฟโอ๊ก
- [ ] ยังไม่ได้แจ้งทุกสาขาเรื่องรูปแบบการกรอกตัวเลขให้เป็นมาตรฐานเดียว
- [ ] สรุปผลโปรโมชันรอบใหม่ (หลังขยาย 2 สัปดาห์) ยังไม่ได้ทำ

### ปัญหา/อุปสรรค
- ตอนนี้ตามงานค้างอยู่หลายเจ้าของพร้อมกัน ทำให้บางเรื่องค้างข้ามสัปดาห์โดยไม่มีใครรู้
- ปิดเดือน ส.ค. ต้องแก้เอกสารซ้ำสองรอบ เพราะข้อมูลปิดเดือนมาไม่ตรงเวลา

### หมายเหตุ
- เดือนนี้เป็นเดือนที่งานเปิดตัวสินค้าใหม่กับงานประจำทับกันหนัก ควรจดงานค้างให้เป็นระบบตั้งแต่ต้นเดือนหน้า
- อยากให้ผู้ช่วย AI ช่วยอ่านบันทึกทั้งเดือน แล้วช่วยจัดลำดับความสำคัญของงานค้างก่อนเปิดตัวกาแฟโอ๊ก

### ติดต่อประสานไว้
- พี่สมชาย — นัดคิวตรวจงานค้างรวมสัปดาห์หน้า
- พี่วิทย์ — ตามรายงานสาเหตุระบบล่มอีกครั้ง
- ฝ่ายการตลาด — นัดวันถ่ายภาพสินค้ากาแฟโอ๊ก
