# ไฟล์ตัวอย่าง (Samples) สำหรับ Hands-on

โฟลเดอร์นี้เก็บ**ไฟล์ข้อมูลตัวอย่าง**ให้ผู้เรียนใช้ในกิจกรรมลงมือทำของแต่ละโมดูล — คัดลอกไปวางไว้ใน working dir (`~/thclaws-2hr`) ก่อนเริ่ม หรือให้ผู้สอนแชร์ผ่านช่องทางออนไลน์

> ⬇️ ลิงก์ดาวน์โหลดไฟล์แต่ละไฟล์และ `samples.zip` อยู่ที่ [README หลัก](../../README.md)

## ไฟล์ทั้งหมด

| ไฟล์ | ชนิด | ใช้ในโมดูล | เนื้อหา |
|------|------|-----------|---------|
| `meeting_notes.txt` | ข้อความ | M3, M4 | บันทึกประชุมวางแผนเปิดตัวสินค้า — ใช้สรุป/แยก action items |
| `notes.txt` | ข้อความ | M3 | บันทึกงานประจำวัน — ใช้สรุปงาน/เตือนงานค้าง |
| `monthly-sales.csv` | CSV | M4 | ยอดขาย 6 เดือน 3 สินค้า — ใช้สร้าง Excel/วิเคราะห์ |
| `customer-contacts.csv` | CSV | M4 | รายชื่อลูกค้า — ใช้สร้างสเปรดชีต/จัดประเภท |
| `meeting-transcript.docx` | Word | M4 | บันทึกประชุมทีมขาย — ใช้ทดสอบอ่าน/สรุปเอกสาร Word |
| `company-policy.pdf` | PDF | M4 | นโยบายบริษัท — ใช้ทดสอบอ่าน/สรุป PDF |

## วิธีใช้ต่อโมดูล

### M3 — เริ่มใช้งานจริง (คำสั่งแรก)
คัดลอก `meeting_notes.txt` ลง working dir แล้วลอง:

```
อ่าน meeting_notes.txt แล้วเขียนสรุปงานเป็น bullet 3 ข้อ ลงไฟล์ work-summary.md
```
หรือ
```
อ่าน meeting_notes.txt แล้วสรุปเป็น bullet 3 ข้อ
```

### M4 — Tools / Skills / MCP (ใช้ case ตัวอย่าง)

**Use Case 1 — สรุปเอกสาร (File tools):**
```
อ่าน company-policy.pdf แล้วสรุปข้อควรรู้ของพนักงานเป็น bullet 5 ข้อ
เขียนผลลัพธ์ลงไฟล์ policy-summary.md
```

**Use Case 2 — สร้าง Excel จากข้อมูล (Xlsx tool):**
```
อ่าน monthly-sales.csv แล้วสร้างไฟล์ Excel ชื่อ sales-report.xlsx
จัดกลุ่มยอดขายแยกตามสินค้า และสรุปยอดรวมแต่ละชนิด
```

**Use Case 3 — รวม+jัดรูปแบบ (Write/Edit):**
```
อ่าน customer-contacts.csv กับ meeting_notes.txt
แล้วสร้างไฟล์สรุปงานเดียวชื่อ work-summary.md ขึ้นมา
```

> สังเกต `[tool: …]` ในคำตอบ — เห็นว่า Agent "ลงมือ" ใช้ tools จริง

### M5 — thClaws.cloud การใช้งาน
โมดูลนี้เป็นการตั้งค่า/สำรวจบริการคลาวด์ (ไม่ต้องใช้ไฟล์ตัวอย่าง):

- เปิด https://thclaws.cloud → ระบุ **3 องค์ประกอบ** (AI Agents Library / Hosted Workspace / AI Model Gateway)
- สร้าง **Access Key** `thc_…` (Dashboard → + New Token) → วางที่ **Settings → API Key → thClaws.cloud (CLI TOKEN)** → ติ๊ก **"Route LLM through gateway"**
- ดูยอดเครดิต/แพ็กเกจที่ Dashboard; (ระดับสูง) ลองสร้าง Hosted Workspace

**งานส่งท้ายคอร์ส (วางแผนงานประจำวัน):** ใช้ `notes.txt` เป็นกรณีตัวอย่างงานซ้ำ:

```
จาก notes.txt อ่านงานที่ค้างอยู่ แล้วช่วยวางแผนลำดับความสำคัญให้ฉันหน่อย
```

## หมายเหตุ

- ไฟล์ทั้งหมดเป็น**ข้อมูลสมมติ** (fictional) สำหรับฝึกอบรม — ไม่ใช่ข้อมูลจริงของบริษัทใด
- ตัวอักษรไทย UTF-8 อ่านได้ครบทั้ง txt/csv; DOCX/PDF สร้างด้วยเครื่องมือของ thClaws เช่นกัน
- ถ้าอยากให้ผู้เรียนได้ "ลองสร้างเอง" ให้เริ่มจากไฟล์ว่าง แล้วให้ Agent สร้างจากคำสั่งแทนการให้ไฟล์สำเร็จรูป
