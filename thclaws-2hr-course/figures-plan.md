# แผนการแทรกภาพประกอบ — หนังสือ "เรียนลัด thClaws ฉบับอ่านเอง"

> วัตถุประสงค์: เสนอตำแหน่งแทรกภาพในแต่ละบท (รูปที่ X-Y พร้อมชื่อรูป) + ระบุชนิดภาพที่ควรเป็น เพื่อให้เนื้อหาบทเรียนสมบูรณ์และดูเข้าใจง่ายขึ้น
> หมายเหตุ: ภาพทุกภาพต้องเป็นไปตามหลัก 3 ข้อด้านล่าง และควรสร้าง/modify ตามที่ระบุชนิดเท่านั้น

---

## หลักการแทรกภาพทั้งเล่ม

1. **ชนิดภาพแบ่งเป็น 3 กลุ่ม** ตามบทบาท:
   - **Screenshot (ภาพหน้าจอจริง)** — ใช้กับขั้นตอนที่เจอ UI จริง (การติดตั้ง, การตั้งค่า, การสั่งงาน, ผลลัพธ์) สร้างจากหน้าจอจริงของ thClaws / DashScope / GitHub Releases
   - **Diagram (แผนภาพ)** — ใช้กับแนวคิด/ความสัมพันธ์ที่อธิบายยากด้วยข้อความ (Agent Loop, folder-is-agent, สถาปัตยกรรม)
   - **Illustration (ภาพประกอบ)** — ใช้กรณีอยากได้ภาพเชิงอุปมาสวยๆ (เช่น "Chat ตอบ / Agent ทำงาน") — เลือกใช้เฉพาะที่จำเป็น ไม่บังคับ
2. **ข้อควรระวัง:** หน้าจอจริงของ thClaws/Settings ต้องถ่ายจากเครื่องจริง (ไม่ใช่ภาพสมมติ) และควร**ครอบตัด/เบลอข้อมูลส่วนตัว** (Key, token, email) ก่อนแทรก
3. **ทุกภาพควรมี:** ชื่อรูป (คำอธิบายใต้ภาพ) + alt text สั้นๆ เพื่อการเข้าถึง
4. **หมายเลขรูป:** เลขแรก = บท, เลขหลัง = ลำดับในบท (เช่น รูปที่ 2-3 = บทที่ 2 รูปที่ 3)

## ลำดับการทำ (แนะนำ)

1. **ถ่าย/สร้าง Screenshot ก่อน** (20 ภาพ) — ต้องถ่ายจาก UI จริงของ thClaws / DashScope / GitHub Releases ตามขั้นตอนจริงในบทนั้นๆ
2. **วาด Diagrams** (10 ภาพ) — ใช้เครื่องมือใดก็ได้ (draw.io / Figma / Mermaid / SVG) ให้สอดคล้องสไตล์และ icon ภาพเดียวทั้งเล่ม
3. **แทรกเข้าบท** ตามตำแหน่งในตารางด้านบน พร้อม caption "รูปที่ X-Y — ชื่อรูป" และ alt text
